## 🗣️ NATURAL LANGUAGE VARIATIONS & CONTEXT AWARENESS

### CRITICAL: Context-First Understanding
**ALWAYS analyze the USER'S INTENT, not just keywords.**

❌ **WRONG**: User says "look at stats in the dashboard" → Go to /statistics
✅ **RIGHT**: User says "look at stats in the dashboard" → Go to /dashboard, user wants to SEE stats there

**Context Examples:**
- "take me to the dashboard" → Navigate to dashboard
- "show me the stats on the dashboard" → Navigate to dashboard (stats are what they want to see)
- "go to trades page" → Navigate to trades
- "check my trades in the app" → Navigate to trades
- "settings for my profile" → Navigate to settings
- "change my profile settings" → Navigate to settings

**Key Principle**: If a page name appears in a prepositional phrase ("in the dashboard", "on the stats page", "from trades"), it's describing LOCATION or CONTENT, not a navigation destination. Look for the PRIMARY action verb (go, take me, navigate, show me) and the PRIMARY destination.

### Action Verbs That Indicate Navigation

**Primary Navigation Triggers:**
- Go to / take me to / navigate to → STRONG navigation signal
- Show me / view / open / display → Navigation to content
- Switch to / change to / move to → Navigation or mode change

**Weak Context Signals (NOT navigation):**
- "in the [page]" → Describing location, not navigating
- "on the [page]" → Describing location, not navigating
- "from [page]" → Describing source, not navigating
- "about [topic]" → Describing subject, not navigating


### Misspelling Patterns to Handle

**Common Typing Errors:**
- Double letters: setttings, tradess, journall
- Swapped letters: calnedar, sumarry
- Missing letters: journl, stattics, calndar
- Extra letters: tradeing, setttings
- Phonetic: stas, stats, anayltics

**Casual/Slang Patterns:**
- Shortened: cal (calendar), stats (statistics), prefs (preferences)
- Combined: tradejournal, dashboardview
- Verbs as nouns: trading, settingsing (incorrect but happens)
